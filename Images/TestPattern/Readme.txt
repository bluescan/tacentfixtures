TacentTestPattern

The original file was created as a TGA using Tacent View. The test pattern is
divided into distinct quadrants. 

Bottom-Right Quadrant:
This quadrant of TacentTestPattern (the 'splash') is from 'UploadMeToday' at
purepng.com.

Top-Right Bottom-Left Quadrants:
These two quadrants are photos taken by me (Tristan Grimmer).

Top-Left Quadrant:
This quadrant contains generated gradients that were created using the Tacent
library.

The pattern has been converted into a number of formats, losslessly where
possible. Some have no alpha signified by an RGB suffix, and some do (RBBA).

The TacentTestPatternRGBA.pvr uses an internal R8G8B8A8 pixel format. Tacent is
able to decode PVR1 (2 and 4 bpp) compressed blocks, but since they must be
power of 2, we chose raw RGBA for this conversion. Alternate conversion choices
may be viewed in the Type_PVR_V3 folder.
