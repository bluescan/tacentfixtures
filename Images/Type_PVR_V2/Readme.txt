Pixel Format Notes

The PVR2 Pixel Format files:

PVR2BPP2_RGBA_TM.pvr
PVR2BPP4_RGBA_TM.pvr

Are unsupported by the Tacent decoder as of November, 2026. There is no exact
published specification for the PVR2 _pixel format_ and no reference source
implementation. PVR2 is not to be confused with PVRBPP2 and PVRBPP4 for which
there IS a reference decode implementation. It's unfortune naming because
somtimes these formats are called PVR2 and PVR4, but the pixel format is PVR1,
just with different bit depths. Also note the file format is independent. Legacy
is V1 or V2. The current PVR file format is V3.
