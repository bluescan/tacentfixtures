# tacentfixtures
Static data used as test cases for both Tacent and TacentView. By and large the fixtures are image files in various formats, animated and not, with and without meta-data.

All of the test fixtures are released _either_ under the ISC licence (like all the Tacent repositories) _or_ under specific permissive licences chosen by the author(s). Inside each sub-folder of Images you will see a Licences.txt file. It will specify what licence applies. Note that some images may require attribution or have requirements/conditions that must be met before use or publication.
